# Decisions

One short record per decision, using `0000-template.md`. Reversing a decision is
fine. Reversing one without writing down what changed is not.

**The stack decisions made before this directory existed are in
`docs/plan/architecture.md` section 2**, as a table giving each choice, the
reason, what would replace it, and the condition that would flip it. That is the
content an ADR carries, and splitting it into eight files that each repeat one
row would make it harder to read, not easier.

Anything decided from here on gets its own file, numbered in order.
